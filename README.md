# MONGOLIAN MEDIA — Солонгос хэлний сургалтын систем
### "Солонгос хэл — өдөр тутам ба ажил" (30 Өдрийн хөтөлбөр + Үсгийн бэлтгэл)

---

## 🌟 Төслийн ерөнхий танилцуулга
**MONGOLIAN MEDIA** апп нь Солонгос улсад ажиллаж, амьдрахаар төлөвлөж буй болон одоо ажиллаж буй монгол хүмүүст зориулан, солонгос хэлний өдөр тутмын болон ажлын байрны яриаг маш богино хугацаанд, цэгцтэй сурахад зориулагдсан гар утас ба компьютерын цогц систем (PWA + REST Server) юм.

- **Үндсэн брэнд**: MONGOLIAN MEDIA
- **Дэд гарчиг**: Солонгос хэл — өдөр тутам ба ажил
- **Загвар**: Minimal Glassmorphism (Гэрэлтэй ба Харанхуй горим)
- **Туслах дүр**: Монгол хүү (уламжлалт дээл, үнэгэн малгайтай туслах зөвлөгч)
- **Эзэмшигч / Админ**: Батцогт (`admin@mongolianmedia.mn`)

## 🚀 Аппыг хэрхэн эхлүүлэх вэ?

### 1. Компьютер дээр шууд нээх:
1. `start_app.bat` файлыг хулганаар хоёр товшиж ажиллуулна.
2. Компьютерын хөтөч автоматаар нээгдэж, сургалтын талбар бэлэн болно.
3. Хаяг: `http://localhost:8080/`

### 2. Гар утсан дээр АПП болгон суулгах (Хамгийн хялбар арга):
1. Компьютер дээрээ `UTASNAAS_KHOLBOGDOKH.bat` файлыг ажиллуулна.
2. Дэлгэц дээр утасны QR код бүхий хуудас нээгдэнэ.
3. **iPhone / iPad (Safari)**:
   - Утасныхаа камераар дэлгэц дээрх QR кодыг уншуулна.
   - Safari дээр нээгдсэний дараа доод талын **Хуваалцах (Share ⎋)** товчийг дарна.
   - **"Нүүр дэлгэц дээр нэмэх" (Add to Home Screen ➕)** дээр дарна.
4. **Android (Chrome)**:
   - Камераар QR кодыг уншуулж Chrome дээр нээнэ.
   - Дэлгэцийн доор гарах **"Апп суулгах" (Install)** товч эсвэл 3 цэг цэснээс **"Нүүр дэлгэцэнд нэмэх"**-ийг сонгоно.
5. Ингэснээр таны утасны дэлгэц дээр **MONGOLIAN MEDIA** албан ёсны бие даасан гар утасны апп болон суух болно!
*(Жич: Таны утас болон компьютер хоёр нэг Wi-Fi сүлжээнд холбогдсон байх шаардлагатай).*

## 📚 Сургалтын хөтөлбөрийн онцлог

### А. Сонголттой "Үсгийн бэлтгэл" модуль (30 өдрөөс тусдаа)
- Үсэг мэдэхгүй хүн: 19 гийгүүлэгч, 21 эгшиг, 7 үндсэн бачим дуу авиа, авиа зүйн дүрмийг эхнээс нь үзнэ.
- Үсэг мэддэг хүн: Шууд 1-р хичээлээс өгүүлбэрийн яриандаа орно.
- Хэзээ ч хүссэн үедээ үсгийн модуль руу буцаж орох боломжтой.

### Б. 30 Өдрийн хөтөлбөр (300 давхардалгүй бодит өгүүлбэр)
- **50% Ажлын байр** (Үйлдвэр, барилга, агуулах, ресторан, цэвэрлэгээ, аюулгүй байдал, цалин, чөлөө авах).
- **50% Өдөр тутмын амьдрал** (Мэндчилгээ, танилцах, дэлгүүр, эмнэлэг, утас интернэт, хүргэлт, байрны эзэнтэй харилцах).
- Өдөр бүр:
  - 10 үндсэн өгүүлбэр (солонгос бичиг, монгол орчуулга, кирилл галиг, ашиглах нөхцөл, дүрмийн 1-2 товч тайлбар, туслах үгс).
  - 5+5 өгүүлбэрээр хувааж үзэх боломж (өдөрт 20–30 минут).
  - Бодит харилцан яриа (A/B дүрээр сүүдэрлэн ярих).
  - 5 асуулттай мини шалгалт (Монгол хэл дээрх дэлгэрэнгүй зөв/буруу тайлбартай).
  - 7, 14, 21 дэх өдрийн давтлага, 30 дахь өдрийн нэгтгэсэн төгсгөлийн сорил.

### В. Аудио сонсох ба Микрофоноор ярих дасгалжуулагч
- Солонгос хүний унаган дуудлага бүхий Web Speech TTS (0.75x, 1.0x, 1.2x хурд тохируулах).
- Микрофоноор өөрийн дууг бичиж, буцаан сонсох.
- Хиймэл оюуны дуудлагын үнэлгээ (0–100 оноо, 75-аас дээш оноогоор тэнцэх, үг үсгийн зөрүүг заах).

## 👑 Админ ба Эрх удирдах самбар (Батцогт)

- **Нэвтрэх имэйл**: `admin@mongolianmedia.mn`
- **Эрх**: Бүх 30 өдрийн хичээл шууд нээлттэй, бүх админ функц идэвхтэй.
- **Админ боломжууд**:
  1. **Төлбөрийн хяналт**: Суралцагчдаас ирсэн банкны шилжүүлгийн хүсэлтийг 1 товшилтоор `Батлах` эсвэл `Цуцлах`. Баталсан даруйд тухайн хэрэглэгчийн бүх 30 өдрийн хичээл нээгдэнэ.
  2. **Нэг удаагийн урилгын холбоос (Invite Link)**: Хүссэн хүндээ зориулан нэг удаа ашиглагдах урилгын код үүсгэж өгөх (ашигласан даруйд автоматаар шатдаг).
  3. **Төхөөрөмжийн хяналт**: Нэг хэрэглэгч зөвхөн 1 зөвшөөрөгдсөн төхөөрөмж дээр ажиллах дүрмийг хянах, шаардлагатай бол төхөөрөмжийг чөлөөлөх.
  4. **Аудит лог**: Хэн хэзээ нэвтэрсэн, ямар үйлдэл хийснийг хянах.

## ⚙️ SMTP Имэйл сервер тохируулах (`config.json`)

`config.json` дотор дараах тохиргоог хийснээр суралцагчдад 6 оронтой OTP код бодит имэйлээр очно:

```json
"smtp": {
  "enabled": true,
  "host": "smtp.gmail.com",
  "port": 587,
  "user": "your_email@gmail.com",
  "password": "your_gmail_app_password",
  "from_email": "MONGOLIAN MEDIA <noreply@mongolianmedia.mn>"
}
```
*(Хэрэв SMTP тохируулаагүй үед сервер консол цонхон дээрээ 6 оронтой кодыг тодоор хэвлэж харуулдаг тул тест хийхэд ямар ч саадгүй ажиллана).*
